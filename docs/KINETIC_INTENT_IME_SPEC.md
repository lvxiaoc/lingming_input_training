# 《意流书码（Kinetic Intent IME）》项目说明书

> **版本定位**：脱离传统字根背诵与字母音码体系，基于**「汉字视觉相连气团 × 起笔与留白势向 × 键盘空间书写同构」**的新一代形码输入法架构设计与验证蓝图。

---

## 1. 立项背景与核心痛点

在前期基于宇浩/黎明拆分的实验验证中，我们实测了以下三条路径，也清晰暴露了现有体系的天花板：

| 试探方案 | 平均码长 | 500 常用字首字唯一率 | 核心手感优势 | 暴露出的致命问题 |
|---|---:|---:|---|---|
| 固定四码截断（一字根两键） | 3.7 键 | 89.6% | 左右手 100% 交替、零同指 | 三块字强截首尾，写字中途「断气」 |
| 相连成块 + 双键全事件流 | 4.69 键 | 94.2% ~ 97.4% | 每个连通块完整闭环、直觉极好 | 多块字长达 6~8 键，实用输入不可接受 |
| 手指合十（1 块压缩为 1 键） | 2.35 键 | 68.0% | 一块一键、起势与留白对称明确 | 22 键两两组合仅 484 格，远不足以承载汉字 |

**结论**：想要同时满足 **① 平均码长控制在 3 键左右（上限 4 键）**、**② 3,500 常用字首位唯一率 ≥ 93%~96%**、**③ 手指在键盘上的移动方向与纸上写字的“起笔→留白→流向”一致**，必须彻底重构底层：**放弃静态字根表，改为「连通气团切分 + 绝对势象与相对跃迁向量双编码」。**

## 2. 数学可行性审计（为什么必须结合“键间相对关系”）

对任意输入法而言，能否在 3,500 常用汉字（GB2312 / 通用规范一级字）中维持低重码，受信息论下界硬约束：

1. **信息熵门槛**：3,500 字至少需要 $\log_2(3500) \approx 11.8\text{ bits}$ 的有效区分度；考虑到字根/笔画的天然偏态分布（如「口、一、木、氵」高频集中），实际需要 **$14\text{–}16\text{ bits}$** 才能使首位唯一率超过 93%。
2. **单纯「1 块 1 键」为什么会崩溃**：
   - 假设去除小指边缘键（`Q/A/Z/P`），舒适区为 **20~22 键**。
   - **单块字**仅有 $22$ 格；**两块字**最大理论容量仅 $22^2 = 484$ 格，而 3,500 字中有超过 **1,400 个两块合体字**——从鸽巢原理出发，无论怎么调键位，纯 2 键两块字都会撞出大量重码。
3. **破局关键 —— 您的「相对关系携带信息」构想**：
   - 传统编码把按键看成**无空间关系的离散符号**（按下 `J` 无论前一键是 `F` 还是 `D` 都只是一串字符 `FJ`）。
   - 如果让**每一个“起笔 × 留白”类别拥有空间上的“左/右（或上/下）同构映位”**，使得：
     - **按键 $k_i$ 本身**：表达第 $i$ 个连通块的「起笔类型 + 留白扩张方向」；
     - **跃迁向量 $\vec{v} = k_{i+1} - k_i$**：物理上直接对应块 1 到块 2 的「书写行进方向（左右横跨 / 上下垂落 / 半包承托）」。
   - 于是每一次两键连击不再只是 $\log_2(22) + \log_2(22)$，而是把**结构拓扑关系（左右 / 上下 / 包围 ≈ +1.5 bits）**天然融进手指在键盘上的**空间位移**中，彻底摆脱无意义的“识别码”。

## 3. 核心设计原则（彻底摆脱宇浩拆分的三大公理）

### 3.1 拆字单元重构：「视觉粘连气团（Qi-Cluster）」而非死板连通分量

如果机械地按“线条断开就拆开”作为字根，`氵` 会被拆成 3 块、`灬` 拆成 4 块、`心` 拆成 4 块，反而破坏整体意象。新系统应采用基于真实矢量笔顺数据（如 MakeMeAHanzi）的**三条几何切分规则**：

1. **交连成一体（物理连通）**：凡笔画在二维轮廓内相交、端点粘连或穿刺的结构，合并为一个气团（如 `中、束、本、五、我、井、重、垂、东`）。
2. **短距聚簇归气（点族自动合团）**：彼此断开但质心间距小于全字框宽度 12%–15%、且方向一致的散点/对称副笔簇（`氵、灬、心、小、八、火、艹、彡、冫`），在预处理图算法中自动聚合为单一气团。
3. **超大单块三拍展开（防单块撞车）**：若整字仅包含 1 个巨型连通气团（如 `甲、由、申、重、垂、电、鬼、龜`），不再强行压缩成 1 键，而是顺着书写时序自然提取其**「首笔起势 → 中腰枢纽（转折/穿插特征）→ 末笔留白去向」**共 3 键，使单块字也能在 3 键内精准区分。

---

### 3.2 单块气团的四维意流特征体系

对每一个切分出来的「气团 $B$」，完全通过几何计算（而非人工记忆）提取以下四个物理直觉特征：

1. **起势轴向（Origin Axis，2 大类 / 5 子势）**
   - **横掠系（从左向右 / 右下斜掠）**：起笔为横 `一`、撇 `丿`、横折 `乛`。
   - **纵落系（从上向下 / 垂点下沉）**：起笔为竖 `丨`、点 `丶`、竖折 `乚`。
2. **留白开口方向（Negative-Space Aperture，8 方位）**
   - 计算气团外包络凸包（Convex Hull）与真实墨迹之间的**最大空白缺口方位**（即它期待下一块“填进来或托上去”的方向）：
     - 右上敞开承托（如 `辶、廴、耂、几`）
     - 右下庇护留白（如 `厂、广、尸、𠂇`）
     - 下盘四散张开（如 `木、人、大、火、八`）
     - 底部垂聚不散（如 `亻、十、丨、中、巾`）
     - 内敛全封/半封（如 `口、囗、日、目`）
     - 顶盖聚拢下庇（如 `宀、冖、艹、竹、人字头`）
3. **张敛程度（Aspect & Expansion Ratio）**
   - 紧凑团块（宽高比近 1:1 且重心居中） vs 宽扁盖底（如 `艹、冖、皿`） vs 细长支柱（如 `亻、刂、卩`）。
4. **末笔收势向量（Ending Stroke Vector）**
   - 末笔笔锋离开纸面的瞬间方向：上挑提 `↗`、平横驻 `→`、悬针垂 `↓`、长捺散 `↘`、回钩蓄 `↖`。

### 3.3 键盘即宣纸：手指移动 = 书写空间流向

把键盘舒适区（推荐 **22 键零小指区**：左 `WERT / SDFG / XCVB` ＋ 右 `YUIO / HJKL / NM`，或标准 **24 键**含 `Q/P` 微调）视为一张微缩宣纸：

```text
         [ 上排：顶部盖覆 · 右上开口 · 仰扬留白 ]
   W(远扬)   E(斜撇开)   R(上提)   T(聚顶)  │  Y(聚顶)   U(上提)   I(右上开)  O(远穹展)

         [ 中排：中宫定桩 · 封口合抱 · 左右平展 ]   ← 合十镜面轴
   S(外栏展) D(立柱撑)   F(平横基) G(封口内) │  H(封口内) J(平定柱) K(分立撑)  L(右展延)

         [ 下排：垂竖归根 · 撇捺下散 · 托底流注 ]
   X(折下散) C(撇下散)   V(横下散) B(垂落根) │  N(垂落根) M(水火散)
```

#### 「键间相对矢量」编码规则（核心创新）

当输入一个由多个气团构成的汉字（$B_1, B_2, \dots, B_n$）时，第 $i$ 键的物理位置由**「自身意流特征」**与**「相对上一块的书写位移 $\Delta P = (B_i.\text{center} - B_{i-1}.\text{center})$」**共同决定：

1. **左右流向（Horizontal Flow：左块 → 右块，如 `休、明、好、相`）**
   - 手指动作映射为**跨手横移**（左手区域 $\to$ 右手区域，或同一手从内向右侧外展）。
   - 例：`木` 落左食下 `V`，`目` 落右手中排 `J`，`相` 的手指运动 literally 是从左下方顺畅滑向右侧中宫，与在纸上先写左木再写右目的空间轨迹同向。
2. **上下流向（Vertical Flow：上块 → 下块，如 `杏、思、意、花`）**
   - 手指动作映射为**同手区或镜像区的纵向沉降**（上排 $\to$ 中排 $\to$ 下排，如 `R/E/T/Y/U/I` $\to$ `F/D/J/K` $\to$ `V/C/B/N/M`）。
   - 例：`杏`（上木下口）与 `困`/`呆` 即使部件相同，因为气团质心偏移 $\Delta y$ 相反，手指向下压还是回扣封口完全不同，天然区分上下倒置与左右/上下异构字（如 `相` vs `杏`、`呆` vs `杏`、`陪` vs `部`、`加` vs `另`）。
3. **内外包孕流向（Enclosure Flow：外框 → 內核，如 `国、困、问、建`）**
   - 外框落入「外翼包护键（`S / L / I / W`）」，随后内核向中轴核心键（`G / H / F / J`）**由外向内回扣收敛**，模拟“先搭屋檐再填核心”的向心感。

## 4. 码长与重码率目标方案（可行甜区设计）

为兼顾**「3 键左右的超短码长」**与**「全字库 94%+ 首位唯一率」**，建议在新项目中实现并对比以下主推编码范式——**「流变三态定音法（Flow-3）」**：

| 字形连通块数 | 编码结构 | 码长 | 空间容量与区分机制 |
|---|---|---:|---|
| **1 气团（独体大块）** | `起势留白(1) + 中腰枢折(1) + 末势收尾(1)` | 2~3 键 | 简单独体字（如 `一、口、木、人`）2 键；复杂单块（如 `重、甲、由、申`）补第 3 键收尾 |
| **2 气团（二分合体）** | `B₁(起+留白键) + B₂(依位移选映位键) + B₂终势/B₁尾笔键` | 3 键 | $22^3 = 10,648$ 理论槽位 + 结构向量约束，彻底消除 `体/休`、`杏/呆` 碰撞 |
| **3 气团（三分合体）** | `B₁(流向位) + B₂(流向位) + B₃(流向位)` | 3 键 | 全流向 3 键完整覆盖，一气呵成（如 `想`、`茶`、`意` 皆仅 3 键） |
| **4+ 气团（繁复合体）** | `B₁ + B₂ + B₃ + B_last` | 4 键 | 四键封顶，绝不出现 6~8 键过长输入 |

**预期核心指标（新项目需实测验证的验收线）**：
- **平均码长**：**2.85 ~ 3.25 键/字**（较双键全事件流缩短近 40%）；
- **3,500 常用字首位唯一率**：**≥ 93.5%**（引入高频简码或次选优化后可达 97%+）；
- **双手与同指舒适度**：零小指外缘键，同指连续大跳 < 3%，中排及近轴一指距离按键占比 ≥ 75%。

## 5. 新项目工程实施路线图（四阶段可落地计划）

建议以独立工程（如 `kinetic-intent-ime`）从零构建离线编译器 + 可视化检验台 + Rime 输入法导出管线：

### Phase 1：全字库视觉连通气团自动提取器（告别宇浩拆分）
- **数据源**：接入开源 **MakeMeAHanzi (`graphics.txt` + `dictionary.txt`)** 或 **GlyphWiki**，包含 9,500+ 繁简汉字每一笔的精确 SVG 贝塞尔路径与笔画顺序。
- **核心算法（Python / TypeScript）**：
  1. 采样每条笔画 SVG 路径为点序列，计算笔画间的最小欧氏距离矩阵。
  2. 距离 $< \varepsilon_1$（相交/粘连）归入同一连通块；
  3. 对距离 $< \varepsilon_2$（如 12% 字宽）的纯点/短撇簇执行聚簇合并（自动识别出 `氵、灬、心、火、八` 而不被拆碎）。
  4. 输出每个汉字的有序气团序列 `blocks[]`，含每块的包围盒 `(x, y, w, h)`、起笔向量、末笔向量、凸包留白最大开口方位角 $\theta_{\text{gap}}$，以及相邻块的相对质心向量 $(\Delta x, \Delta y)$。

### Phase 2：意流特征聚类与“合十同构”键位映射
- 使用无监督聚类（或基于书法五势规则树），把全字库切出的高现身气团归并到约 **20~24 个主意象位**（保证任意陌生字块都能按“起笔 + 留白方位”在 0.3 秒内直觉反应出键位，**零死记硬背根表**）。
- 建立每个意象位的**「同构映位对」（如左区 vs 右区、上行 vs 下行）**，使第二块的键位选择严格服从相对位移 $\Delta P$（左 $\to$ 右 / 上 $\to$ 下 / 外 $\to$ 内）。

### Phase 3：模拟退火多目标优化与 3,500 / 6,763 字压力评测
- 编写命令行评测器，运行多目标搜索（Simulated Annealing），目标函数联合优化：
  $$\mathcal{L} = w_1 \cdot \text{重码字数}_{3500} + w_2 \cdot \text{同指连击率} + w_3 \cdot \text{中心距偏离} - w_4 \cdot \text{空间方向同构匹配度}$$
- 强制输出全字库冲突清单、重码热力图、以及手指在 2D 键盘上流过轨迹与汉字质心移动轨迹的相关系数（`Spatial Flow Alignment Score`）。

### Phase 4：真机入力闭环（Rime 引擎挂载 + 意念练功台）
- **导出 Rime 方案**：生成 `yiliu.dict.yaml` 与 `yiliu.schema.yaml`，直接部署到 macOS 鼠须管（Squirrel）/ Windows 小狼毫（Weasel），在真实文本编辑中校验手感。
- **配套肌肉记忆道场**：复用三景深静心练习台，取消字母提示，仅在屏幕中央绘制汉字的**「气团空间流动箭矢」**与手部对称落点，直接建立“见字写势、手随心动”的条件反射。
